# snowflake-tagging-framework
Digitalization of Core Functions in Rogers Communications by Manisha Kriplani 

## Rogers Communications 

## Overview

This project showcases the digitalisation of core data governance functions at Rogers Communications using enterprise-scale automation, metadata governance, dynamic masking, and AI-driven governance architecture.

The solution was designed and implemented as part of:

- Real-world enterprise governance transformation initiatives at Rogers Communications
- Academic submission for the ISB Chief Digital & AI Officer (CDAIO) Program

The project demonstrates how large-scale enterprises can modernize governance operations through automation, scalable metadata management, policy-driven security, and intelligent governance workflows.
